# estudos-java

Repositório de estudos de **Java e Programação Orientada a Objetos**, criado para acompanhar o curso completo de Java (do zero ao avançado), com anotações, exercícios resolvidos, exercícios propostos e projetos práticos.

Cada aula fica em um arquivo comentado, com explicações escritas direto no código, servindo também como material de consulta rápida.

## Tecnologias

- Java (versão LTS atual)
- IntelliJ IDEA
- Git / GitHub
- Maven (gerenciamento de dependências)

## Estrutura do projeto

```
estudos-java/
├── out/                        # Arquivos compilados (.class)
├── src/
│   └── estrutura_sequencial/
│       └── Aula01.java
├── .gitignore
└── estudos-java.iml
```

Os pacotes são organizados por tema, seguindo a ordem do curso.

## Como executar

Clone o repositório:

```bash
git clone https://github.com/<seu-usuario>/estudos-java.git
```

Abra a pasta no IntelliJ IDEA (ou na IDE de sua preferência) e execute o método `main` da classe desejada.

Pelo terminal:

```bash
cd src
javac estrutura_sequencial/Aula01.java
java estrutura_sequencial.Aula01
```
